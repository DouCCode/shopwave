# 🛍️ Shopwave

## 📖 About The Project

ShopWave is an online shopping platform designed to provide users
with a simple and convenient shopping experience.

## ✨ Features

List of the project featurs: 

- User authentication (Login & Register)
- Browse products
- Search and filter products
- Add products to cart
- Manage shopping cart


## 🛠️ Technologies Used

- **Frontend:** HTML CSS
- **Backend:** Django
- **Database:** sqlite3
- **Styling:** Tailwind CSS
- **Tools:** Git, Github, VS Code
